Expense Tracker Backend ⚙️

This repository contains the backend service for the Expense Tracker mobile application.

Built with PHP and Laravel, the backend provides API endpoints that allow the mobile application to communicate with the server and handle application data.

✨ Features

* REST API: Provides endpoints for mobile application functionality.
* Authentication: Supports user authentication.
* Expense Management: Handles expense-related operations.
* Client-Server Communication: Enables communication between the mobile application and the backend.
* Data Management: Processes and manages application data.

🛠️ Technologies

* PHP
* Laravel
* REST API
* Database Integration

🏗️ Architecture

The backend acts as the server-side component of the Expense Tracker application.

* Frontend: React Native with TypeScript
* Backend: Laravel with PHP
* Communication: REST API

🚀 Getting Started

Prerequisites

* PHP
* Composer
* A database supported by the project
* Laravel-compatible development environment

Installation

1. Clone the repository:

git clone <repository-url>

2. Navigate to the project directory:

cd ExpenseBackend

3. Install the PHP dependencies:

composer install

4. Create your local environment configuration:

cp .env.example .env

5. Generate the application key:

php artisan key:generate

6. Configure your database connection in the .env file.
7. Run the database migrations if the project uses Laravel migrations:

php artisan migrate

8. Start the development server:

php artisan serve
